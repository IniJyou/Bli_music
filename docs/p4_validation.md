# P4 功能与验证

2026-11-03。P4 使用已有开发依赖。类型检查、构建、46 项逻辑测试、13 项 P2 桌面回归和 7 项本地音频检查通过。P4 的 4 组桌面检查全部通过，使用独立资料库和静音测试音频。

## 外部歌单

从「资料库 → 导入外部歌单」读取公开的网易云音乐或 QQ 音乐歌单。每次最多读取 500 首，界面显示已读取数量与歌单总数。自动匹配按歌名、歌手、时长和常见版本标记排序。只有满足三项信息且领先其他候选的版本会预选。可重试、改搜、手动粘贴 B 站链接、选择分 P、试听和跳过。试听使用独立音频，暂停主播放器，保存后按原歌单顺序创建本地歌单。同一分 P 去重，已有手动曲目信息保留。

实测网易云热歌榜读取 200 首，QQ 音乐历届奥运会主题曲歌单读取 28 首。桌面检查覆盖无效链接后的重试、真实 B 站匹配、停止批量匹配、手动指定 `BV1CGxAzwECr` 的第二分 P、实际解码试听及保存。900×680 窗口下导入对话框通过横向布局检查。需要权限或平台接口临时受限时显示相应错误。[网易云热歌榜](https://music.163.com/#/playlist?id=3778678) [QQ 音乐测试歌单](https://y.qq.com/n/ryqq/playlist/3222752131)

### 2026-11-04 批量匹配提速

搜索和保存前的视频信息查询最多三路并行。桌面主进程错开发起请求，窗口隐藏时仍可继续。一次匹配中相同搜索词共用搜索结果，每首仍按自己的歌手和时长评分。停止后正在处理的请求会收尾，继续时仅查询待匹配和失败的曲目。待确认的曲目可逐首重试。保存复用已检查的视频信息，剩余查询按 BV 号合并，再按原顺序提交并保留手动选中的分 P。

同机使用真实 QQ 音乐歌单和匿名 B 站搜索计时，从点击「自动匹配」到全部 28 首处理完毕。旧版用时 19.46 秒，优化版在可见测试窗口和隐藏窗口分别用时 7.36 秒和 7.37 秒。28 首的逐首状态一致，4 首自动匹配项用 0.62 秒按原顺序写入隔离资料库。类型检查、构建和 49 项逻辑测试通过。受控桌面检查覆盖停止、续跑、重复查询合并和保存失败后保留已检查结果，验证同一视频的手动 P2 与自动 P1 均保存正确。[QQ 音乐测试歌单](https://y.qq.com/n/ryqq/playlist/3222752131)

连续进行实测时，首轮 P4 回归收到一次 B 站 HTTP 412，匹配暂停并提示保留已有结果。间隔后重跑，四组 P4 桌面检查全部通过。

## 响度均衡与托盘

从「资料库 → 备份与设置」开启响度均衡。播放时收集约两秒有效音频的 RMS 样本，估计每首曲目的响度，对较响的曲目衰减、较轻的曲目适当提升。修正在 −12 dB 到 +6 dB 之间，音量与修正相乘后上限为 1。缺少有效样本时使用原音量，曲目切换时重新估计。

使用两段合成 WAV 验证实际 Web Audio 增益。默认 5% 音量下，较响样本增益低于 0.025，较轻样本高于 0.088，关闭均衡回到 0.05。真实 B 站流在开启均衡时也向测量节点提供了非零采样。托盘验证覆盖关闭后隐藏窗口、后台继续播放和恢复窗口。右键托盘图标可播放、暂停、切歌或退出，开启「关闭窗口时收起到托盘」后可用窗口关闭按钮收起。退出仍走原有的播放状态保存流程。[Electron 托盘文档](https://www.electronjs.org/docs/latest/api/tray)

## Windows 媒体控制

Windows 的系统媒体会话读取标题与已知歌手，控制播放、暂停、上一首、下一首和进度跳转。测试通过 Windows 媒体会话管理器对隔离应用身份发送实际系统命令，观察播放器状态和播放位置变化。物理键盘和耳机媒体键可在有真实设备时试用。系统会话在开始播放后可用。[Media Session 规范](https://www.w3.org/TR/mediasession/) [Microsoft 系统媒体控件](https://learn.microsoft.com/en-us/windows/apps/develop/media-playback/integrate-with-systemmediatransportcontrols)

运行 `node.exe scripts/run.mjs smoke-p4` 可复现桌面检查。总报告在 `.artifacts/p4/smoke-result.json`，包含测试目录和结果。原生文件选择步骤使用隔离测试路径，音量差异的实际听感可通过日常使用确认。

## 2026-11-04 轻量化对照

同一台 Windows 电脑、同一 Electron 45.1.0 运行时及隔离资料库，每种情况各运行三次并取中位数。启动计时从启动 PowerShell 到恢复的队列可播放，旧路径用每次构建的启动脚本配合相同源码。运行占用对比优化前后的真实 Electron 窗口，打开恢复了 500 首曲目的播放队列并解码本地 WAV，采样 6.5 秒。CPU 为 Electron 进程组的总采样值，内存为各进程的私有内存之和。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 重复启动 | 2.66 秒 | 0.96 秒 |
| 聆听页空闲 CPU（5.2 秒采样） | 2.42% | 0.35% |
| 打开 500 首队列播放时的 CPU | 6.24% | 2.47% |
| 同一队列场景的私有内存 | 652 MiB | 554 MiB |
| 同一队列场景的界面主线程任务总时长 | 4.14 秒 | 0.75 秒 |
| 构建产物 `out/` | 2.05 MB | 1.15 MB |

启动验证覆盖首次构建、直接复用、构建产物缺失后重建和源码变更后重建。播放进度保持更新，聆听页播放时恢复场景动效，隐藏窗口时动效暂停且音频继续。暂停恢复后的空闲采样期间没有新增播放进度写入。两张纸纹图由 RGBA PNG 无损重编码为灰度加透明度的 PNG，解码后逐像素相同。构建产物体积含按需加载的代码，Electron 运行时目录另外约 357 MiB。P5 单独测量安装包及安装后体积。
