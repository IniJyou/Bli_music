# 界面第一版

本文保留第一版历史记录；用户随后认可了第二版方向，当前运行界面见 `ui_v2.md`。

日期：2026-10-30。用户在观看 MV 风格分析后明确授权“先按你这个改第一版”。当前已实现并自动验证，审美、实际声音和操作体验待用户验收。

后续视觉修正：按用户要求移除首页与三种沉浸场景中的人物及座椅，保留雨窗、空桌、咖啡与唱片，并将不使用人物装饰的偏好写入 `project_plan.md`。本次通过类型检查、构建与四个实际页面截图检查；播放相关逻辑没有修改，未重复运行下方第一版的音源测试。无人物版本截图位于 `.artifacts/ui-v1/no-figures`，通过已有 Electron 离线生成，没有请求音频。

## 视觉与交互

- 日常聆听页以深蓝侧栏、纸白底色和朱橙操作色建立层次，主视觉采用青蓝、明黄与斜线分割，减少圆角卡片堆叠。
- 雨窗、空桌、咖啡与唱片为自行绘制的 SVG；根据用户后续反馈，已移除人物及座椅，今后的界面装饰不使用人物形象。只参考用户 MV 的配色、构图与氛围，没有把 MV 截图、歌词或音视频打包进应用。使用本机字体与原生 CSS，不依赖远程字体或新资源下载。
- 导入入口收至顶部；本次聆听展示真实视频分段与时长，可选择分段、双击播放。上一段、下一段只操作当前视频的分段，不等同于已实现跨视频队列。
- 新增沉浸页：左侧原创海报，右侧真实曲目信息与歌词状态，可切换青蓝、朱橙、明黄场景。Escape 返回聆听页。
- 底部播放器保持固定，视图共享同一音频元素，切换页面与配色不会重新加载音源；保留播放、暂停、拖动进度、音量和重新获取连接。
- 雨线、漂浮唱片与蒸汽采用缓慢轻动效，系统要求减少动态时停用。按钮保留键盘焦点标记；连接详情移入原生模态窗口。
- 默认窗口改为 1280×860，最小仍为 900×680。较小窗口允许内容纵向滚动，底部播放控制始终可见。

## 体验入口与边界

运行根目录的 `start-p0.cmd`。可先打开“一首单曲”，点击播放，再进入“沉浸聆听”；右上角圆点切换配色，左上角返回或按 Escape。多分段视频可使用下拉框、列表和上一段/下一段。

已通过同一启动脚本打开新版，并从 Windows 进程确认标题为 `Bli Music` 的可见窗口，记录在 `.artifacts/ui-v1/launcher-result.json`。

本次交付是现有 P0 的界面改版，没有把 P1～P3 标记完成。本地歌单、跨视频队列、搜索与歌词匹配仍在后续阶段；当前歌词区域明确显示“歌词功能准备中”，不使用模拟歌词。场景选择和音量尚未跨重启保存。最终应用名称、图标与开源许可证仍待用户决定。
