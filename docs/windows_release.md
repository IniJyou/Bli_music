# Bli Music Windows 首版

版本为 0.5.0，适用于 Windows 10/11 x64。

## 安装和启动

安装文件名为 `Bli-Music-0.5.0-win-x64-setup.exe`。安装向导可选择安装位置，并创建桌面和开始菜单快捷方式。安装完成后运行 Bli Music。

公开版本从 [GitHub Releases](https://github.com/IniJyou/Bli_music/releases/latest) 获取，安装包和 `SHA256SUMS.txt` 位于版本附件。

安装包使用原创咖啡杯图标。个人构建使用未签名的可执行文件，Windows 可能显示未知发布者。构建文件的 SHA-256 摘要随安装包提供。

## 资料库与缓存

默认主目录为 `D:\BliMusicData\当前Windows用户名`，资料库在 `data` 子目录，缓存和日志在 `cache` 子目录。没有 D 盘的电脑使用当前用户 AppData 下的 `BliMusic` 目录。在「资料库 → 备份与设置」可查看实际数据路径、打开目录、导出资料库及创建备份。

如需自定位置，可在启动前设置环境变量 `BLI_MUSIC_HOME` 为一个可写的绝对目录。目录应位于应用安装目录之外。安装新版本使用同一个目录即可恢复歌单、喜欢、历史、编辑信息、队列和设置。

## 从开发版迁移

1. 在原开发版的「资料库 → 备份与设置」导出资料库 JSON，然后退出开发版。
2. 打开安装版，在同一设置页选择「导入资料库」，预览后选择「恢复」。
3. 本地音乐重新用「导入本地音乐」选择原文件。相同路径会恢复文件读取权限，并保留原来的喜欢、编辑和歌单信息。
4. 检查歌单和恢复的播放位置，确认后再整理旧开发目录。

JSON 保存音乐资料与播放状态。本地音频和在线音源由各自原位置提供。更换电脑时需要重新选择本地音乐。

## 更新和卸载

退出播放器后运行新版安装包，使用原安装位置完成覆盖安装。资料库和缓存位于独立目录。卸载程序保留这些用户数据，原始本地音频由用户自行管理。

## 已知边界

在线歌曲依赖平台接口和当前可访问的音轨。需要登录、受限、无独立音轨、限流和网络错误会显示状态。外部歌单每批最多 500 首，候选歧义需要确认。首版提供中文界面，跳过账号同步、歌词和译文。

物理耳机按键、实际听感和安全软件提示需在使用设备上确认。自动验证的具体条件见 `p5_validation.md`。
