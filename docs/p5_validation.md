# P5 Windows 交付验证

日期为 2026-11-07。0.5.0 Windows x64 安装包与本机技术验证已完成。验证环境为 Windows 10.0.26300 x64、Electron 45.1.0 和 Node.js 24.16.0。

## 已实现

- Windows x64 NSIS 打包配置。复用现有 Electron，安装向导可选择目录。
- 发行文件清单限于运行所需的代码、界面素材、咖啡杯图标及许可材料。
- 安装版把数据放在独立目录，通过 `BLI_MUSIC_HOME` 可调整位置。开发版继续使用原资料库布局。
- 打包环境忽略开发服务器地址，开发回归入口只在开发环境启用。
- 安装、迁移、升级和卸载说明，以及第三方组件许可声明。

## 已执行

- TypeScript 检查与生产构建通过。
- 51 项 Node.js 逻辑测试通过，包含升级前后数据路径稳定与非法路径拒绝。
- 13 项 P2 资料库桌面检查和 7 项本地音频检查通过，覆盖保存、重启续播及 9 种扩展名实际解码。
- 真实独立程序已解码本地 WAV 与 B 站音轨，拖动到 7.5 秒后退出，再启动恢复暂停状态。资料库、喜欢、手动歌名、歌手、歌单、队列和设置保留。
- 0.4.9 安装验证包覆盖升级到 0.5.0 后，读取原资料库并实际恢复播放。0.4.9 使用同一份代码，仅用于检查安装器版本升级。
- 全新 0.5.0 安装启动正常。带空格的安装路径、桌面与开始菜单快捷方式通过检查。
- 安装结束已清理安装器生成的缓存副本。卸载后资料库和原始本地音频保留，测试安装与快捷方式已清理。
- 已检查程序和安装器的咖啡杯图标、版本信息、MIT 与第三方声明。程序包只含所需代码和素材，保留 Electron 的许可文件。

## 复现

```powershell
node.exe scripts/run.mjs dist
node.exe scripts/smoke-package.mjs
node.exe scripts/run.mjs smoke-p5
```

打包命令可能获取下载清单中的官方构建工具，按 `p5_download_plan.md` 的授权规则执行。安装验证使用 `.artifacts/p5` 中的独立目录。该脚本检查已有 Bli Music 安装后再执行安装测试。报告分别位于 `.artifacts/p5/package-result.json`、`install-result.json` 和 `distribution.json`。

## 使用设备确认

安装包采用个人未签名构建，Windows 可能显示未知发布者。Windows 10 其他版本兼容性、物理耳机按键、屏幕切换效果和实际听感需在目标设备上确认。安装、开发版资料迁移及升级步骤见 `windows_release.md`。
