# 第二版运行界面

日期：2026-10-30。用户已认可第二版视觉方向，现已接入真实播放器并完成技术回归。方向认可与运行版的声音、操作体验验收分别记录，后者仍待用户确认。

## 最终行为

- 雨窗、漂流、日光沿用已认可方向稿的构图，分别使用雾蓝雨景、橙色漂浮杯碟、黄色留白与长阴影。原创 SVG 位于 `src/renderer/src/assets/scenes`，构建不依赖 `.artifacts` 下的概念稿。
- 自制界面没有人物，取消封面缩略图与海报边框；场景覆盖整个窗口，纸感连续。原 MV 仅作本地分析参考，没有将截图、音频或视频作为应用素材。
- 顶部输入 BV/AV 或完整视频链接。读取后显示真实分段标题和 UP 主，分段下拉框可切换，旁边刷新图标重新获取音源；长标题截断时可悬停查看完整标题。
- “本次列表”展开当前视频的真实分段，点击一行即播放；支持滚动与选中状态。它不是跨视频队列，也不是持久化歌单。
- 底部是真实播放、暂停、上一段、下一段、进度和音量控制；右下角切换场景。沉浸模式收起导入与列表入口，按 Escape 返回，音频元素始终保留。
- Escape 先关闭连接信息窗口，再关闭分段列表或退出沉浸模式；关闭列表后焦点回到列表按钮。原生按钮、下拉框和进度条保留键盘操作与可见焦点。
- 场景切换淡入淡出，雨线、杯碟缓慢运动；非当前场景的动画暂停，系统减少动态时停用动画。静态纹理与场景组件不会随播放进度重新生成。

## 使用与边界

仍可双击根目录 `start-p0.cmd`，它使用现有依赖本地构建和启动，不自动下载。也可对已构建版本运行 `node.exe scripts/run.mjs start`。

已通过现有 Node 启动器打开第二版运行界面，并立即从 Windows 进程确认标题为 `Bli Music` 的原生可见窗口；记录位于 `.artifacts/ui-v2/launcher-result.json`。交互启动的输出与错误记录分别位于同目录 `interactive.stdout.log`、`interactive.stderr.log`。

歌词区域显示“歌词功能准备中”，没有使用方向稿曲名或模拟歌词。本地资料库、跨视频队列、搜索和歌词按后续阶段实现；场景和音量尚未跨重启保存。本次 UI 接入不代表完整 P1 完成，声音与实际设备体验仍待用户验收。
