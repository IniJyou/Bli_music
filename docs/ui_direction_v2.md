# 第二版视觉方向校准

日期：2026-10-30。第一版去掉人物后，用户仍认为缺少参考 MV 的感觉。用户明确选择同时保留安静雨窗与明亮超现实两种情绪，随场景切换。

用户随后以“对味了”认可此方向，现已接入真实播放器；本文件保留概念稿记录，运行版及验证见 `ui_v2.md`。

## 对照后的判断

第一版借用了配色与咖啡馆题材，但室内静物偏多、尺寸偏大，仍以粗体标题、侧栏与海报容器组织画面。重新对照参考 MV 的 00:27、02:52、03:06 等帧后，第二版重点转为少量主体与大留白、透视和长阴影、连续纸感、细雨，以及漂浮与斜向切面。审美是否接近用户期待仍需用户判断。

不使用人物。所有场景图形和纹理由本地 HTML、SVG、CSS 自行绘制；原 MV 帧只用于本地分析，没有放入方向稿，也没有下载新素材或依赖。没有应用 ImageGen 或调用收费 API。

## 可查看的方向稿

入口为 `.artifacts/visual-direction-v2/index.html`，底部“雨窗 / 漂流 / 日光”可切换场景。亦可通过已有 Electron 打开独立预览：

```powershell
node.exe .artifacts/visual-direction-v2/capture.mjs --preview
```

| 场景 | 构图与情绪 |
| --- | --- |
| 雨窗 | 全窗口雾蓝玻璃、稀疏细雨、远处的小桌和咖啡、倾斜投影；控件融入环境 |
| 漂流 | 橙色大色面、米白斜切、悬浮杯碟与细弧线，少量静物缓慢漂浮 |
| 日光 | 大片黄色留白、小杯子与长阴影，延续静物与尺度对比 |

文字与控制区在切换时保持位置，背景构图随场景改变。原生 CSS 包含慢速雨线和漂浮动效，并响应系统减少动态的偏好。截图使用静止状态，动态速度的主观感受尚待预览。

截图 `rain.png`、`orange.png`、`yellow.png` 及离线渲染记录 `capture.json` 位于同一目录。三个场景均实际切换并渲染，1280×802 内容区没有横向溢出。该尺寸为当前环境下的实际内容区，不等于最终应用的窗口尺寸。

## 当前边界

本次只制作视觉方向稿，未修改播放器源码、未重新进行音源测试、没有 Git 提交或推送。方向稿中的参考曲名只用于排版；没有连接音源、显示实际歌词或实现播放、列表、链接导入。只有场景切换是可操作的预览功能，页面有“视觉方向稿 / 未连接音源”的明确标记。

此概念稿与当前可播放应用是两个入口。当前应用已采用第二版场景，技术验证见 `ui_v2.md` 和 `p0_validation.md`；概念稿本身没有增加音源功能，也不能将方向稿或 UI 改版视作 P1、歌词功能完成。
